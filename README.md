A deterministic Python program that writes one funny text message from your future self — under 200 characters, no setup, no context, just the message as it would arrive. The future self burned their one time-travel trip to deliver a very important piece of news about the Wi-Fi password.

## Run it

```sh
python3 main.py
```

This writes the single-line message to `/output/entry.txt`.
